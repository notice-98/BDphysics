# BDphysics

[웹에서 실행](https://voxel-dynamics-studio.sungsungjinutella.chatgpt.site/) · [GitHub](https://github.com/notice-98/BDphysics)
마인크래프트 디스플레이용 브라우저 물리 애니메이션 편집기입니다.

## 실행과 저장
Node.js로 이 폴더에서 `node serve.mjs`를 실행한 뒤 http://127.0.0.1:4173/ 를 여세요. 설치나 빌드가 필요하지 않습니다.
파일 메뉴에서 New Project를 만들고 .byphsics로 저장합니다. 전용 파일은 버전, 배치, 모델, 그룹, 물리 설정, 연결, 폭발, 키프레임과 사용자 피봇을 압축해 보관합니다. 기존 .bdphysics와 JSON도 열 수 있습니다. 작업은 브라우저에도 자동 저장됩니다.
.bdengine/.bdstudio의 gzip·base64·PRJ2 형식을 읽고 블록·아이템의 정적 행렬과 중첩 그룹을 가져옵니다. 애니메이션·텍스트·소리·카메라는 제외합니다. Minecraft 공식 서버의 플레이어 머리 텍스처는 보존합니다. 중첩된 비균일 크기로 발생한 shear도 Minecraft의 좌·우 회전과 크기로 분해해 유지합니다.

건축물은 파일 메뉴에서 .litematic(Litematica v4~7), .schem(Sponge v1~3), .schematic(MCEdit), .nbt(구조물), .bp(Axiom v0~1)를 엽니다. 블록과 blockstate를 유지하고 공기·structure_void는 제외합니다. 원본 영역 간 상대 좌표를 유지하며 건축물의 가장 낮은 구석을 월드 원점으로 옮깁니다. 가져올 때 실제 블록/가상 블록을 선택하고, 건축물 전체를 하나의 상위 그룹으로 묶습니다. Litematica 영역은 그 안의 하위 그룹으로 보존합니다. 가상 블록은 원본 텍스처·blockstate·히트박스를 유지한 반투명 고정 충돌체입니다. 데이터팩에는 가상 블록의 표시 엔티티를 생성하지 않습니다. 실제 블록은 기본 고정 상태로 가져오며 앵커 버튼으로 고정을 풀 수 있습니다. 블록 엔티티의 내용물·텍스트 및 일반 엔티티는 가져오지 않습니다. 현재 게임 버전에 없는 블록·상태는 오류로 알립니다. 구형 MCEdit 형식에서 저장하지 않은 울타리·벽 등의 주변 연결은 차이가 있을 수 있습니다.

## 배치와 편집
- 버전 오른쪽의 렌더 모드에서 높은 품질(강한 명암·그림자), 기본 명암(그림자 없는 부드러운 조명), 히트박스(기본 명암 위 실제 충돌체 표시)를 선택합니다. 화면 설정은 브라우저에 저장되고 물리 기록과 데이터팩에는 영향을 주지 않습니다.
- 선택이 없으면 기준 블록 한 칸의 중심 (0.5, 0.5, 0.5)에 추가합니다. 선택이 있으면 전체 선택의 모델을 바꾸고 변형·물리 설정을 유지합니다.
- 목록은 가로 10개의 3D 모델 미리보기와 전체 스크롤을 사용합니다. 같은 재질과 나무 계열이 모이도록 정렬합니다. 문 같은 두 블록 모델은 아래쪽 블록을 미리 봅니다. 스크롤에 가까운 미리보기부터 생성해 캐시합니다.
- 그리드는 1픽셀(1/16블록), 이동은 0.5픽셀(1/32블록), Shift 미세 이동은 1/256블록입니다. 바닥 접촉 시 한 번 걸립니다.
- 질량·마찰·탄성·재질·고정·속도·모델·공통 블록 상태·히트박스 편집은 전체 선택에 적용합니다. 서로 다른 값은 혼합 상태로 표시합니다.
- T/R/S 이동·회전·크기, B 쌓기(크기를 유지한 채 화살표 방향으로 맞닿게 연속 복제), Ctrl 크기 비율 유지, Z 중심/아래 구석 피봇, Alt+이동 화살표로 물체를 유지하고 피봇만 이동, X 월드/로컬 축입니다.
- G 그룹화/해제, Ctrl+C/V 제자리 복사/붙여넣기, Ctrl+D 제자리 복제, Ctrl+Z 취소, Ctrl+Y 또는 Ctrl+Shift+Z 재실행, Delete 삭제입니다. 모든 단축키는 물음표 안내에 있습니다.
- 트리에서 그룹 전체 접기/펼치기와 다른 그룹으로 드래그를 지원합니다. Ctrl+드래그로 영역 선택, Ctrl+Shift+드래그로 추가 선택합니다. 물체 하나를 선택하고 같은 재질 선택 버튼을 누르면 같은 종류를 장면 전체에서 선택합니다(블록 상태 무관). 영역 선택에만 적용 체크박스는 현재 선택한 물체의 종류로 Ctrl 영역 선택을 제한합니다. 우클릭에서도 같은 재질 선택을 지원합니다. 빈 그룹과 빈 상위 그룹은 자동 삭제합니다. 우클릭 메뉴로 이름·복사·복제·그룹·대칭·삭제를 실행합니다.
- 물체 메뉴의 NBT · 태그에서 추가 SNBT와 엔티티 태그를 입력합니다. 전체 선택에 적용하고 전용 파일에 보관하며 데이터팩 summon에 반영합니다. 배치·모델·애니메이션 필드는 편집기로 관리합니다.
- 목록 끝의 눈 아이콘은 편집 화면만 숨깁니다. 물리와 데이터팩에는 물체가 남습니다.

## 도형과 래그돌
배치 도구 순서는 블록 → 아이템 → 도형 → 가상 블록 → 래그돌입니다. 묶기/해제는 하나의 토글 버튼이며 바닥 맞추기 도구는 제거했습니다. 물리 바닥과 이동 중 바닥 걸림은 유지합니다. 렌더 방식 오른쪽의 선택 테두리 토글은 물체를 감싸는 사각 표시만 숨깁니다.
도형은 삼각형 면으로 구성한 로우폴리 구·정사면체·정팔면체·정십이면체·정이십면체·토러스·원기둥·원뿔·사각뿔·삼각기둥·원·삼각형을 제공합니다. 정육면체와 평면은 제외했습니다. 각 삼각형은 얇은 흰색 콘크리트 블록 세 개를 비균일 변형해 정확히 덮으며, 좌·우 회전으로 shear를 데이터팩에서도 보존합니다. 모든 면은 한 그룹으로 묶고 기본 결속력은 최대입니다. 곡면 분할은 낮음/기본/높음으로 조절합니다. 정사면체·정십이면체는 원래의 정규 비율을 유지하며 한 면을 수평으로 놓습니다. 미리보기는 도형별로 기울기 없는 시점을 사용하고, 평면 도형은 정면에서, 토러스는 구멍이 보이는 높은 시점에서 표시합니다. 같은 평면의 삼각형 내부 대각선은 미리보기 윤곽에서 제외합니다. 블록을 층층이 쌓는 이전 도형 생성 방식은 제거했습니다. G로 만든 일반 그룹의 기본 결속력은 유지합니다. 파괴 임계값 0은 자동 결속 없는 편집용 그룹으로 사용하며, 하위 그룹의 결속과 직접 만든 접합·줄·축 고정은 유지합니다. 그룹도 축별 크기 조절을 지원하고 Ctrl을 눌렀을 때만 비율을 유지합니다.
래그돌 도구에서 닉네임을 조회하거나 64×64·64×32 PNG를 불러옵니다. 파일은 기본형(4px 팔)/슬림형(3px 팔)을 선택합니다. Head Editor나 픽셀 편집기는 제공하지 않습니다. 닉네임은 PlayerDB로 계정을 조회하고 MCHeads에서 원본 스킨을 받습니다. 기본은 스티브이며 얼굴을 보이는 방향으로 배치합니다.
머리·몸통·좌우 위팔/아래팔·허벅지/종아리를 그룹으로 만들고 목·어깨·고관절은 볼 관절, 팔꿈치·무릎은 범위가 있는 경첩으로 연결합니다. 같은 부위의 표시 조각은 강체로 붙이고 다른 부위는 물리적으로 독립합니다. 기본형은 19개, 슬림형은 27개 머리 디스플레이를 사용해 각 면의 원본 픽셀 비율을 보존합니다. 원본 SkullModel의 정점·UV와 PlayerModel의 기본/슬림 UV를 대조했습니다. 관절 연결점 근처에서만 접촉 여유를 주어 경직을 피하고 나머지 부위끼리의 충돌을 유지합니다.
데이터팩에서 새 PNG 스킨 부위를 표시하려면 래그돌 창의 데이터팩 텍스처 변환에서 MineSkin API 키로 변환해야 합니다. PNG는 MineSkin에 전송되며 키는 프로젝트나 자동 저장에 포함하지 않습니다. 미등록·변환되지 않은 머리가 사용되면 UI와 내보내기 함수가 추출을 막습니다. 완성된 Minecraft TextureValue가 들어 있는 기존 BDE 머리는 바로 사용할 수 있습니다. 키가 없는 장면 편집과 물리 미리보기는 가능합니다. 새 스킨을 실제 MineSkin 키로 변환하는 업로드는 아직 검증하지 않았고 요청·대기열·실패 흐름은 모의 응답으로 검사했습니다. 19개 부위·9개 관절의 변형 재생은 실제 Fabric 26.3에서 확인했습니다. 기존 물리 테스트가 모든 부위에 같은 스티브 머리 텍스처를 잘못 대체한 문제를 제거했습니다. 앞으로 게임용 래그돌 테스트는 실제로 등록된 부위별 텍스처가 있어야 준비할 수 있습니다. 새 스킨의 게임 외형은 아직 검증하지 않았습니다. 변환이 완료된 머리는 편집기에서도 내보내기에 사용하는 등록 텍스처를 표시하며, 미등록 초안만 로컬 PNG로 표시합니다.
BDE의 기존/최신 완성된 머리 텍스처, 초안 PNG, 정적 플레이어 부위를 가져옵니다. 애니메이션과 텍스트는 가져오지 않습니다.

## 물리와 애니메이션
질량, 마찰, 반발력, 중력, 초기 속도, 순간 충격, 지속 힘, 던지기와 회전 속도를 설정합니다. 힘과 던지기는 물체 또는 중첩 그룹을 대상으로 합니다. 그룹의 힘은 총 질량에 따라 분배합니다. 힘·던지기 화살표로 방향과 세기를 편집합니다. 끝점은 0.5픽셀 간격으로 움직이고 Shift는 1/256블록 눈금으로 미세 조절합니다. 수직·수평·45도 근처에서 방향이 한 번 걸리고 6도 이상 계속 움직이면 풀립니다. X/Y/Z 성분이 중심선(0)을 지날 때도 한 번 걸립니다. Shift는 방향·중심선 걸림을 해제합니다. 화살표 머리는 늘려도 비율을 유지합니다.
동작 탭의 기류는 회전 가능한 XYZ 박스 안에 방향성 힘을 가합니다. 흡인은 원뿔 영역의 물체를 꼭짓점으로 끌어당기며 중심 부근에서 속도를 감쇠하고 중력을 보정해 머물게 합니다. 계속 작동을 끄면 시작/끝 시점을 지정할 수 있습니다. 영역 마커의 위치·회전·XYZ 크기는 키프레임으로 보간합니다. 기류의 중앙과 흡인의 꼭짓점에 있는 작은 구는 영역 크기와 무관한 크기를 유지합니다. 힘은 물체의 질량 중심에서 영역 포함 여부를 판단합니다.
두 물체를 선택하고 J 또는 연결 탭의 접합을 누르면 현재 배치로 연결합니다. 모서리 접합은 한 축으로 꺾이는 경첩, 꼭짓점 접합은 자유 회전하는 볼 관절입니다. 각 물체의 질량·중력·마찰·탄성과 충돌을 유지하며 연결은 끊어지지 않습니다. 두 지점 찍기로 첫 물체와 둘째 물체의 지점을 차례로 고르면 정렬하여 접합합니다. 접합된 하나를 클릭하면 연결된 전체를 선택해 이동합니다. Alt+클릭으로 개별 선택합니다. 선택한 그룹 내부를 클릭하면 직속 하위 그룹을 선택하고 반복하면 단일 물체까지 선택합니다. G 그룹 내부의 접합에도 별도 고정 관절을 중복하지 않습니다. 축 고정은 지정점을 공간에 고정하고 월드 X/Y/Z 또는 T/R 마커로 임의 회전축을 설정합니다. 점 고정 모드는 모든 방향으로 회전합니다. 고정점 편집 시 몸체 로컬 연결점을 함께 계산해 시작 시 갑작스러운 위치 교정을 방지합니다. 자성은 N/S극의 끌어당김·밀어냄과 금속 반응을 사용합니다. 물체 메뉴의 히트박스 편집에서 화면의 충돌 상자를 클릭해 선택하고 T/R/S로 위치·회전·크기를 바꿉니다. 선택한 조각은 청록색으로 강조합니다. Ctrl 크기 조절은 XYZ 비율을 유지하며 선택한 모든 물체의 같은 번호 조각에 편집을 적용합니다. 상자 추가·제자리 복제·삭제·원본 복원을 할 수 있습니다.
오른쪽 키프레임 탭을 없애고 하단 타임라인에서 동작 시점·시작/끝과 키프레임을 드래그합니다. 우클릭으로 시점을 입력하거나 삭제하고, 클릭 후 Delete로도 삭제합니다. K 또는 키프레임 추가 버튼으로 물체·아이템의 위치·회전 또는 기류·흡인 마커의 위치·회전·크기를 기록합니다. 물체 키프레임은 하단 타임라인에서 편집하며 별도 오른쪽 탭을 만들지 않습니다. 뒤쪽 키프레임을 선택한 뒤 보간 곡선 버튼, 더블 클릭 또는 우클릭의 보간 곡선으로 앞 구간을 편집합니다. 6개 프리셋과 cubic Bézier 제어점 그래프·숫자 입력을 제공하며 위치·회전·XYZ 크기 및 물리 계산에 같은 보간을 사용합니다. 곡선은 끝 키프레임의 easing [x1,y1,x2,y2]로 저장합니다.
과거 파일의 물체 키프레임·물리 전환은 재생 호환성을 유지합니다. 큰 그룹과 작은 그룹을 계층 연결하고 충격량 임계값 또는 예약 해제로 붕괴를 설계합니다.
타임라인 배속 구간은 시작·끝 손잡이로 조절하고 막대로 이동하며, 더블 클릭이나 라벨 클릭으로 배율(.1×~16×)과 정확한 시점을 입력합니다. 구간 밖은 1×이고 중첩은 허용하지 않습니다. 물리는 원래 시간축으로 계산하며 재생과 데이터팩만 동일한 시간 매핑으로 변환합니다. 내보내기는 초당 20프레임으로 보간하고 폭발 시점도 함께 변환합니다. 매우 긴 감속은 내보내기 메모리 제한을 적용합니다.
줄과 스프링은 블록·블록 상태·두께를 지정합니다. 줄은 편집 중에도 최대 길이를 초과할 수 없습니다. 물체 이동을 길이 경계로 투영하고 고정점 이동·줄 단축 시 연결된 전체 그룹을 강제로 길이 안으로 옮깁니다. 회전·크기가 적용된 로컬 연결점을 사용하며, 여러 고정점 때문에 길이 제약을 동시에 만족할 수 없는 편집은 취소합니다. 스프링은 이 제한을 적용하지 않습니다. 줄은 검정 콘크리트, 스프링은 흰 콘크리트가 기본입니다. 그룹 매달리기는 하나의 줄로 전체 질량을 지지합니다. 공간 고정점과 폭발 마커는 클릭해 화살표로 옮깁니다.
스프링은 기본적으로 늘어났을 때 당깁니다. 압축될 때 밀어내기는 별도 옵션입니다. 강성과 감쇠를 조절할 수 있습니다.
폭발은 위치·시점·반경·충격량을 설정합니다. 실제 게임의 16프레임 폭발 텍스처를 사용하고 사이즈·양·확산 속도를 조절합니다. 적용 여부는 데이터팩 파티클 포함을 결정하며 편집기에서는 미리 볼 수 있습니다.
물리는 120 Hz로 계산하고 초당 20프레임으로 기록합니다. 접촉 반복 계산과 CCD를 보강했으며, 형상을 유지하면서 붙어 있는 아이템 픽셀 충돌체를 합칩니다. 장면의 형상·배치·힘·키프레임·연결이 정확한 거울 대칭을 만족하면 그 대칭을 유지하도록 계산해 정면 충돌과 수직 낙하에서 수치 오차가 옆 방향 속도로 증폭되지 않게 합니다. 비대칭 모델·기울어진 표면·중심을 벗어난 힘·회전이 있으면 해당 제약을 적용하지 않습니다. 실제 강체 그룹 내부의 충돌은 연결이 해제될 때까지 제외합니다. 경첩·꼭짓점으로 연결된 독립 몸체 사이의 충돌은 유지합니다. 스프링은 회전 관성까지 포함하는 제약 솔버로 계산하고 기본 모드에서 느슨해지면 제약을 제거합니다. 미리보기는 실제 경과 시간으로 재생합니다. 높은 탄성의 충돌체를 기준으로 반발력을 합칩니다.

## 기록 종료
자동 종료는 움직임이 1.5초 동안 충분히 작아지고 이후 예약 동작·키프레임·물리 전환·힘 종료가 없을 때 기록을 끝냅니다. 이후 예약 동작이 있으면 기다리고 계속 계산합니다. 자동 종료를 끄면 입력한 길이까지 기록합니다.
계속 작동하는 기류·힘, 바깥으로 날아가는 물체, 감쇠가 작은 스프링·회전 관절, 자성의 반복 운동은 종료되지 않거나 오래 걸릴 수 있습니다. 지속 동작의 종료 시점과 감쇠를 설정하거나 기록 중지 버튼으로 원하는 시점까지 보관합니다. 일정 시간 뒤에도 움직이면 기록 상태에 원인을 표시합니다. 시간 상한 대신 기록 메모리 약 256 MiB와 작업 영역 이탈을 감시해 브라우저를 보호하고, 중단된 구간도 미리보기·내보내기에 사용할 수 있게 보존합니다. 무한한 길이의 프레임을 메모리에 저장할 수 있다는 의미는 아닙니다.

## 모델과 데이터팩
기본 버전은 Java 26.3이며 1.19.4부터 26.3까지 25개 정식 버전의 바닐라 블록·아이템·블록 상태 자산을 포함합니다. 게임의 모델 상속, variants/multipart, 면별 UV, 모델 회전, 투명·애니메이션 텍스처를 읽습니다. 블록 상태와 회전·비균일 크기·대칭을 충돌체에 반영합니다. 아이템은 보이는 형상에 두께를 준 충돌체를 사용합니다.
상자와 구리 골렘 동상은 공식 26.3 클라이언트 모델 생성 코드를 실행해 추출한 실제 정점·UV·부위 회전과 버전별 텍스처를 사용합니다. 구리 골렘의 네 자세와 산화·밀랍, 단일·좌·우 상자를 지원합니다. 배너 등 다른 특수 렌더러는 간소화된 형상으로 게임과 차이가 있을 수 있습니다. 커스텀 리소스팩 모델은 지원하지 않습니다.
내보낸 ZIP을 월드/datapacks에 넣고 /reload 후 /function <이름>:start를 실행하세요. pause, resume, reset, stop, clear 함수와 장면 JSON이 포함됩니다. 버전을 변경하면 모델·상태·충돌을 갱신해 다시 계산합니다.

데이터팩의 마커·디스플레이 선택자를 실행 중인 차원으로 제한하여 한 게임 틱에 한 프레임씩 진행합니다. 차원 제한 없는 선택자로 인해 같은 애니메이션이 세 번 진행되던 오류를 수정했습니다. 이전에 내보낸 ZIP은 다시 내보내야 수정이 적용됩니다.

데이터팩은 실제 20 TPS 시점을 유지하면서 변한 변형 필드만 갱신합니다. 고정된 물체와 빈 프레임은 명령을 내보내지 않고 움직이는 프레임만 분기합니다. scene.json의 재생성 가능한 모델 데이터도 제거해 용량을 줄입니다.

## 성능
가상/실제 전환 시 이전 모델을 즉시 제거하고 비동기 모델 갱신의 오래된 결과를 취소합니다. 재질 캐시에 투명도·발광 설정을 포함하고 가상·로딩 중 모델을 인스턴싱에서 제외합니다.
동일한 불투명 블록은 GPU 인스턴싱으로 묶어 그리며 개별 선택·변형·숨김을 유지합니다. 같은 텍스처의 면을 병합하고 지오메트리를 공유합니다. 물리 속성만 바꿀 때 모델을 다시 만들지 않으며, 재생 중 고정 물체의 변형과 타임라인의 정적 요소를 반복 갱신하지 않습니다. 고정된 건축물은 동일한 포즈를 공유해 불필요한 물리 계산과 프레임 복제를 생략합니다.
로컬 소프트웨어 WebGL 검사에서 512개 돌 블록의 그리기 호출이 3,089회에서 18회로 줄었고 평균 프레임 시간은 약 84ms에서 48ms로 줄었습니다. 8,192개 고정 블록의 8초 기록은 약 5.88초에서 22ms로 줄었습니다. 수치는 동일 환경의 예제 장면 기준이며 실제 기기와 장면에 따라 달라집니다.

## 범위와 검증
물체 8,192개, 그룹 64개, 연결 128개, 폭발 32개, 기류·흡인 32개, 힘 이벤트 128개, 물체·영역별 키프레임 64개를 지원합니다. 장면 길이에는 기존 8/30초 제한을 두지 않습니다. 좌표 범위는 ±4,096블록이며 건축물의 전체 영역은 8백만 칸까지 읽습니다. 프로젝트 압축 해제 크기는 32 MB까지 지원합니다.
줄은 거리 제약을 8개의 표시 블록으로 시각화합니다. 줄 자체의 질량·충돌·엉킴은 계산하지 않습니다. 기류·흡인은 장애물에 의한 차폐나 유체 흐름을 해석하지 않고, 자성은 연출용 거리 인력·반발력입니다. 폭발은 거리 기반 충격량이며 장애물의 차폐를 계산하지 않습니다. 붕괴는 연출용 임계값을 사용하며 구조 공학의 응력 해석은 아닙니다. 찌그러짐·천·액체는 지원하지 않습니다.
데이터팩은 기록된 물리를 20 게임 틱에 1초로 재생합니다. 게임 지형과 런타임 충돌을 다시 계산하지 않습니다. 환경은 편집기에서 가상 블록 또는 고정 물체로 구성하세요.
X/Y/Z 정면 반사, 실제 가마솥과 철괴·다이아몬드·네더의 별·돌 아이템의 수직 낙하, 비대칭 충돌, 얇은 벽의 고속 충돌, 겹친 그룹, 고강성 스프링, 키프레임 전환, 인스턴스 선택·재생·숨김, T/R/S/B 단축키를 검사했습니다. 물리, 파일 복원, 첨부 BDE 두 파일과 실제 카탈로그 모델 4개, 실제 Litematica·Axiom 예제 13개와 공식 구조물, 형식별 배열 경계 조건, 쌓기, NBT, 최적화 프레임 비교, 실제 브라우저의 화살표·트리·다중 선택·3D 목록·파티클·내보내기를 검사했습니다. 25개 버전의 생성 형식을 검증했으며 모든 Minecraft 클라이언트에서 실행한 검증은 아닙니다.

실제 Minecraft Java 26.3 / Fabric 0.19.5의 별도 검증 월드에서 46개 시나리오, 2,610개의 재생 틱, 171,280회의 변형 성분 비교를 통과했습니다. 낙하·탄성·X/Y/Z 반사·회전 형상·CCD·가마솥/아이템·마찰·힘/던지기·계층 붕괴·줄/스프링·기류/흡인·자성·접합/축 고정·커스텀 히트박스·blockstate·키프레임/배속·폭발·가상 블록 제외·래그돌을 포함합니다. float32 직렬화 오차는 성분당 0.000003 이내로 검사했습니다. 일시정지·재개·초기화·삭제와 네더·엔드의 재생은 추가 3,588회 검사를 통과했습니다. 차원 검증에서는 원점 청크를 명시적으로 로드하고 검사 후 로드 설정을 해제했습니다. 결과는 tests/in-game-26.3-results.json에 있습니다.
