# BDphysics

마인크래프트 디스플레이 엔티티로 물리 애니메이션을 만드는 웹 편집기입니다. 블록과 아이템을 배치하고, 힘이나 연결을 설정한 뒤 시뮬레이션 결과를 데이터팩으로 내보낼 수 있습니다.

**[BDphysics 실행하기](https://voxel-dynamics-studio.sungsungjinutella.chatgpt.site/)**

기본 게임 버전은 Java Edition 26.3입니다. 편집기에서 1.19.4부터 26.3까지 25개 버전 중 하나를 선택할 수 있습니다.

## 주요 기능

- 블록·아이템 배치, 블록 상태 설정, 히트박스 편집
- 질량, 마찰, 탄성, 중력, 자성 설정
- 던지기, 지속 힘, 폭발, 기류, 흡인
- 중첩 그룹과 붕괴 설정, 줄, 스프링, 경첩·볼 관절, 축 고정
- 타임라인에서 동작 시점과 키프레임 편집, 베지어 보간 곡선과 구간별 배속
- 건축물 파일 가져오기, 로우폴리 도형과 플레이어 래그돌 생성
- 프로젝트 저장과 데이터팩 내보내기

## 작업 순서

1. 새 프로젝트를 만들고 사용할 게임 버전을 선택합니다.
2. 블록이나 아이템을 추가합니다. 기존 건축물이 있다면 파일 메뉴에서 불러올 수 있습니다.
3. 물체의 물리 속성을 설정하고, 필요한 그룹이나 연결을 만듭니다.
4. 동작 탭에서 힘을 추가하고 타임라인에서 실행 시점을 조절합니다.
5. 시뮬레이션을 기록해 결과를 확인한 뒤 프로젝트와 데이터팩을 저장합니다.

키프레임은 하단 타임라인에서 추가합니다. 물체의 위치·회전과 기류·흡인 마커의 위치·회전·크기를 조절할 수 있으며, 키프레임 사이의 보간 곡선도 직접 편집할 수 있습니다.

자동 종료를 사용하면 움직임이 멈추고 이후에 예약된 동작이 없을 때 기록이 끝납니다. 계속 작동하는 힘이나 반복 운동이 있는 장면은 직접 기록을 중지하거나 종료 시점을 지정해야 합니다.

### 가상 블록

데이터팩에 표시되지 않는 고정 충돌체입니다. 원본 블록의 모델·텍스처·히트박스를 유지하고 편집기에서는 반투명하게 보입니다. 애니메이션의 받침대나 벽을 만들 때 사용합니다.

건축물을 가져올 때도 가상 블록으로 불러올 수 있습니다. 가져온 건축물은 하나의 상위 그룹으로 묶입니다.

### 그룹과 연결

그룹의 파괴 임계값으로 결속력을 조절합니다. 값을 `0`으로 설정하면 그룹 안의 물체가 각각 움직입니다. 직접 만든 줄·접합·축 고정과 하위 그룹의 결속은 유지됩니다.

접합은 물체를 고정하는 대신 연결 지점에서 움직이도록 합니다. 모서리 접합은 경첩처럼 한 축으로 꺾이고, 꼭짓점 접합은 볼 관절처럼 회전합니다.

### 래그돌

닉네임을 입력하거나 스킨 PNG를 불러와 플레이어 래그돌을 만듭니다. 파일을 불러올 때는 기본형과 슬림형 중 하나를 선택합니다.

새 스킨을 데이터팩으로 내보내려면 MineSkin API 키를 사용해 부위별 텍스처를 변환해야 합니다. 이 과정에서 스킨 이미지는 MineSkin으로 전송되며, API 키는 프로젝트 파일에 저장되지 않습니다. 변환 전에도 편집과 시뮬레이션은 가능합니다.

이미 등록된 Minecraft 머리 텍스처는 바로 내보낼 수 있습니다. 미등록 텍스처가 남아 있으면 데이터팩 내보내기가 차단됩니다.

## 파일 불러오기와 저장

프로젝트는 파일 메뉴에서 `.byphsics`로 저장합니다. 배치, 그룹, 물리 속성, 연결, 동작, 키프레임 등을 함께 보관합니다. 브라우저에도 작업이 자동 저장되지만, 다른 컴퓨터에서 이어서 작업하려면 프로젝트 파일을 저장해야 합니다.

| 형식 | 불러오는 내용 |
| --- | --- |
| `.byphsics` | BDphysics 프로젝트 |
| `.bdphysics`, JSON | 이전 형식의 BDphysics 프로젝트 |
| `.bdengine`, `.bdstudio` | 블록·아이템과 그룹의 정적 배치 |
| `.litematic` | Litematica v4–7 건축물 |
| `.schem`, `.schematic` | Sponge v1–3, MCEdit 건축물 |
| `.nbt` | Minecraft 구조물 |
| `.bp` | Axiom v0–1 블루프린트 |

건축물의 블록 상태는 유지됩니다. 공기, 블록 엔티티의 내용물·텍스트, 일반 엔티티는 가져오지 않습니다. BDEngine 파일의 애니메이션·텍스트·소리·카메라도 제외됩니다.

## 데이터팩 사용

내보낸 ZIP 파일을 월드의 `datapacks` 폴더에 넣고 다음 명령을 실행합니다. `<이름>`에는 내보낼 때 지정한 데이터팩 이름을 입력합니다.

```mcfunction
/reload
/function <이름>:start
```

`pause`, `resume`, `reset`, `stop`, `clear` 함수로 재생을 제어할 수 있습니다.

데이터팩은 편집기에서 계산한 애니메이션을 재생합니다. 게임 안에서 물리를 다시 계산하거나 실제 월드의 지형과 충돌하지는 않습니다. 주변 지형에 부딪히는 연출이 필요하면 편집기에 가상 블록이나 고정 물체를 배치해야 합니다.

재생 속도는 20 게임 틱당 1초를 기준으로 합니다. 서버의 TPS가 낮아지면 게임 안에서 재생도 느려집니다.

## 기본 조작

| 조작 | 단축키 |
| --- | --- |
| 이동 / 회전 / 크기 | `T` / `R` / `S` |
| 크기를 유지하며 연속 복제 | `B` |
| 그룹화 / 그룹 해제 | `G` |
| 접합 | `J` |
| 키프레임 추가 | `K` |
| 피봇 중심 / 아래 구석 전환 | `Z` |
| 월드 / 로컬 축 전환 | `X` |
| 제자리 복제 | `Ctrl+D` |
| 실행 취소 / 다시 실행 | `Ctrl+Z` / `Ctrl+Y` |
| 삭제 | `Delete` |

이동 간격은 기본 0.5픽셀이며, `Shift`를 누르면 미세하게 조절합니다. 크기 조절 중 `Ctrl`을 누르면 XYZ 비율을 유지합니다. 이동 도구에서 `Alt`를 누르고 화살표를 움직이면 물체 대신 피봇만 이동합니다.

전체 단축키는 편집기 상단의 물음표 메뉴에서 확인할 수 있습니다.

## 로컬 실행

Node.js가 설치된 환경에서 아래 명령을 실행합니다.

```sh
git clone https://github.com/notice-98/BDphysics.git
cd BDphysics
npm start
```

브라우저에서 [http://127.0.0.1:4173/](http://127.0.0.1:4173/)를 엽니다. 별도의 패키지 설치나 빌드는 필요하지 않습니다.

테스트는 `npm test`로 실행합니다. 인게임 검증 기록은 [tests/in-game-26.3-results.json](tests/in-game-26.3-results.json)에 있습니다.

## 현재 제한

- 기본 Minecraft 자산을 사용합니다. 커스텀 리소스팩 모델은 지원하지 않으며, 일부 특수 렌더러는 게임과 외형이 다를 수 있습니다.
- 줄 자체의 충돌이나 엉킴은 계산하지 않습니다. 기류·흡인·폭발은 장애물의 차폐를 계산하지 않으며, 자성은 연출용 인력·반발력입니다.
- 찌그러짐, 천, 액체 시뮬레이션은 지원하지 않습니다.
- 기록 길이에는 고정된 시간 제한이 없지만 메모리와 작업 영역 제한이 있습니다. 물체는 장면당 최대 8,192개까지 사용할 수 있습니다.
- 실제 MineSkin 업로드와 새로 변환한 스킨의 인게임 외형은 아직 검증하지 않았습니다.

## 사용한 자산

Three.js, Rapier, JSZip의 라이선스는 [dist/vendor](dist/vendor)에 있습니다. 게임 데이터 출처는 [dist/data/SOURCE.txt](dist/data/SOURCE.txt), 클라이언트 자산 출처와 해시는 [dist/vanilla/index.json](dist/vanilla/index.json)에서 확인할 수 있습니다.

Minecraft 자산의 권리는 Mojang Studios / Microsoft에 있습니다. BDphysics는 비공식 도구입니다.
